# Lab Activity 4: Login and Registration

This project demonstrates a simple registration, login, and dashboard flow using HTML, CSS, and JavaScript.

## User Manual

1. Open `register.html` in a browser.
2. Enter your full name, username, email, password, and confirmed password.
3. Click **Register** to go to the login page.
4. Enter a username and password, then click **Login**.
5. The dashboard displays the registered username and email in a table.
6. Click **Log out** to return to the login page.

The account username and email are stored in browser local storage for this front-end activity. This is not production authentication.
